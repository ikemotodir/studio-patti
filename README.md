## 触り方

- `start.bat` … ローカルサーバーを立ててブラウザで開く（確認用）
- `build.bat` … 素材を全部書き出し直す（Aseprite + Python が必要）

`build.bat` がやること:

1. `Patti.aseprite` / `Mayu.aseprite` / `Bonbon.aseprite` からスプライトシートを書き出し
2. `shade_*.py` で夜の部屋に合う色へ落とす（原本の .aseprite には触らない）
3. `make_room.py` で部屋を描く（照明計算込み）
4. `prep_media.py` `prep_gallery.py` `prep_book.py` で重い素材をWeb用に最適化
5. `make_closeups.py` で寄りの画面と座標データを書き出し

手で描き直したい部分は `overrides\` に同名のPNGを置くと最優先で上に乗ります。

## ギャラリーの購入リンク

`gallery_links.json` は**作品の番号**をキーにしています。

```json
{ "7": "https://buy.stripe.com/..." }
```

作品名やファイル名を変えてもリンクは外れません。作品を差し替えたら、
その番号のURLだけ書き換えてください。番号がどの作品にも当たらない場合は
ビルド時に警告が出ます。

## 技術

素材はすべてドット絵（384×240）で、`image-rendering: pixelated` で拡大表示。
アニメーションはスプライトシート + CSS `steps()` と小さなJSプレイヤー。
ライブラリ・ビルドツールは使っていません（静的HTML1枚）。
